# ローカル開発チェックリスト

Hermes Voice Suite に小さな変更を加えるときの、最小限の確認手順です。
本番サービスへの接続や再起動を行わず、ローカルで安全に確認することを目的とします。

## 作業前

- Python 3.11 以上を使用する。
- `.env`、トークン、音声、文字起こし、OAuth ファイル、SSH 秘密鍵をコミットしない。
- Discord、STT、TTS、ネットワーク処理はアダプター境界に保つ。
- 音声ストリーミングを変更する場合は、2,000 ms の early task、400 ms の overlap、
  1 ユーザーにつき 1 つの early task という既存の制約を確認する。

## ローカル確認

依存関係を含む開発環境が準備済みなら、リポジトリのルートでテストを実行します。

```bash
pytest -q
```

Discord に接続せず音声ボットの設定を確認する場合は、preflight を実行します。

```bash
.venv/bin/voice-bot --check
```

## コミット前

1. `git diff --check` で空白エラーを確認する。
2. `git status --short` で意図しない生成物がないことを確認する。
3. `git diff` を読み、秘密情報やランタイムデータが含まれていないことを確認する。
4. 実行したテスト、結果、変更ファイル、次のアクションを記録する。

コード、設定、依存関係、音声経路、ルーティングを変更した場合は、完了またはデプロイ前に
VPS Codex auditor の監査が必要です。ドキュメントだけの変更でも、本番操作は行わず、
デプロイが必要な場合は別の技術タスクとして扱ってください。
